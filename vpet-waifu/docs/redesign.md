## 4. Единая система состояния

### Валюта
Один символ — **¥** — во всех текстах и вместо иконки `Icons.Rounded.Paid`
(это глиф доллара; используется в 11 местах: `Widgets.kt:253`,
`HomeScreen.kt:521,1277,1382`, `ShopScreen.kt:358,404,421`,
`ActivitiesScreen.kt:206,299`, `GameScreen.kt:585`, `VPetApp.kt:406`).
Единый форматтер `formatMoney(amount)` → «N ¥» применяется к строкам
`sick_buy_medicine`, `story_reward_money`, `ach_rich`, `recap_shift`,
`recap_goal`, `goal_earn`, `goal_reward`, `notify_shift_body` и к call-sites
`ShopScreen.kt:238/375/404`, `PetBubble.kt:176` (там сейчас «1178¥» без
пробела), `ProfileScreen.kt:569`.

### Один баланс на всех экранах
Источник один (Room-flow → `PetViewModel.uiState`), рассинхрон — в
презентации: каждый `MoneyPill` держит собственную медленную пружину
(`animateIntAsState(spring(StiffnessLow))`, `Widgets.kt:213-217`), а кошелёк
меняется каждые 3 с; свежесмонтированный экран показывает актуальное число,
живущий — догоняющее. Правка: анимация поднимается в `VPetApp` (один
анимированный int), все три пилюли получают уже готовое значение и совпадают
попиксельно каждый кадр. Суммы, которые кошельком не являются (`paidOut`
за смену, `totalEarned`, прогноз `projectedPayout`, ставка копилки), получают
подписи и перестают выглядеть как баланс.

## 6. Структура экранов (сверху вниз)

### Дом
1. Шапка: мини-LevelRing · имя (тап → диалог переименования) · MoneyPill ·
   **шестерёнка → экран «Настройки»**.
2. Сцена с персонажем (статус-чип, реплика, всплывающие +¥/+EXP).
3. Условные карточки (болезнь → желание → глава → годовщина → рекап →
   событие) — переписанные тексты, по одной строке.
4. Активная смена + чипы активных баффов.
5. Статы (голод/энергия/настроение).
6. **Объединённый блок «Прогресс»**: бар уровня + «До N уровня — X опыта»;
   ниже две метрики пассивного дохода чипами («¥/мин», «лимит ¥/день»,
   бейдж «на смене — пауза») + «?».
7. Действия: Покормить · Сон · Погладить.

Убрано: SettingsCard (5 свитчей) и поле «Её имя» — на отдельный экран
настроек; первичный ввод имени — в онбординг (первый запуск).

### Дела
1. Заголовок + MoneyPill.
2. Sticky: карточка активной смены (или строка «Мало энергии — нужны еда
   или сон»).
3. «Работа»: карточки — тайл, название (1 строка, ellipsis), чипы
   «+137 ¥» «−15 энергия» «−5 настроение» «30 мин», CTA **«На смену»**.
4. «Учёба»: то же с чипом «+62 EXP», CTA **«Начать»**.

Locked-карточка: вся карточка 45 % альфы + бейдж «10 ур.» в углу; красный
текст и активная кнопка убраны.

### Магазин
1. Заголовок + MoneyPill.
2. **Горизонтальные табы категорий** (Еда · Подарки · Таблетки · Баффы ·
   Комната · Снаряжение · Наряды), sticky.
3. **Один sticky-баннер** «Она занята до HH:MM — еда недоступна» вместо
   повторов на каждой карточке.
4. Карточки: цена всегда справа в фиксированной колонке; недоступность =
   приглушение цены и карточки, причина — только в баннере или бейдже уровня.
5. Предупреждение о таблетках — «?» в заголовке секции, не текст между
   секциями.

### Игра
1. Заголовок + чип настроения.
2. **Сегмент-контрол** Ловкость / Ритм / Память (один контейнер, выбранный
   сегмент — акцент; вместо трёх разноцветных карточек).
3. Компактный хедер: рекорд выбранной игры + подсказка (одна строка).
4. Игровое поле фиксированной пропорции (вместо `weight(1f)` на всю высоту):
   внутри персонаж-превью и CTA «Играть» — пустого контейнера нет.

### Она
1. Заголовок (имя) + чип уровня привязанности.
2. **История**: глава M/8, прогресс-бар, цель главы одной строкой.
3. **Привязанность**: уровень + бар, чип «+X/20 сегодня», строка
   иконок-источников, «?».
4. **Статистика** («Жизнь вместе»).
5. Цель недели (чипы наград).
6. Путь (Focus): до 6 уровня — одна заблокированная строка с бейджем.
7. Достижения: **3 ближайших к разблокировке + кнопка «Все (14)»**
   (bottom sheet).
8. Гардероб: **рендер только при ≥2 нарядах**.
