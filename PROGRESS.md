## Что не сделано

- **Нет звука.** В ТЗ он упомянут как поощряемая инициатива, не как требование.
      Приоритет отдан корректности данных и восьми работающим уровням.
- **Нет 3D-моделей аппаратов.** МКС — параллелепипед с подписью, а не модель из
      NASA 3D Resources. Загрузчик glTF не подключался: на общий вид уровня это
      почти не влияет, а бюджет ушёл на физику и данные.
- **Пояс Койпера и облако Оорта не кликаются как отдельные слои в реальном масштабе.**
      В сжатом режиме облако Оорта скрыто намеренно (см. решения ниже).
- **Тени не считаются.** Кольца Сатурна не бросают тень на планету, спутники не
      затмевают друг друга. Включение теней для точечного источника на таких
      масштабах даёт артефакты и стоит дорого на телефоне.
- **Прецессия и возмущения планетных орбит не учитываются** — только вековые линейные
      члены из приближения JPL. Для интервала 1800–2050 гг. это единицы угловых минут,
      за его пределами точность падает, но приложение это не заявляет.
- **APK — debug-сборка, не release.** Release потребовал бы генерации keystore и
      подписи ключом, который негде безопасно хранить в этом окружении.
      Debug-APK устанавливается и запускается, чего достаточно для проверки.
- **На реальном устройстве не запускался.** Проверка шла в headless Chromium с
      программным WebGL (SwiftShader). Логика, шейдеры и отсутствие ошибок консоли
      подтверждены; настоящий FPS на телефоне не измерен.

## Найдено и исправлено по ходу

Каждое из этих мест было увидено на скриншоте, а не угадано.

| Что было | Почему | Как исправлено |
| --- | --- | --- |
| Маркеры скоплений и туманностей рисовались цветными квадратами | плоскость с обычным материалом без радиального затухания | компонент `GlowSprite` с гауссовым спадом альфы; для войдов — `SoftDisc` с контуром |
| Освещённая сторона Земли была целиком оранжевой | подкраска терминатора спадала как `exp(-12·cosθ)` — на пол-планеты | спад ужат до `exp(-42·cosθ)`, амплитуда снижена вдвое |
| Небо выглядело мутными серыми пятнами | панорама 2K растягивается на 360° при поле зрения 55° — шестикратное увеличение | панорама убрана; звёзды генерируются в галактических координатах, полоса Галактики — отдельным шейдером |
| На уровне Земли звёзд не было вовсе | небесная сфера радиусом 400 оказалась за far-плоскостью камеры (136) | радиус приведён к 55 |
| Реликтовое излучение заливало весь кадр | сфера с `BackSide`, а камера снаружи — видна внутренняя поверхность дальней стороны | `FrontSide`, прозрачность 0,34, камера отодвинута за пределы оболочки |
| Камера стартовала внутри пояса Койпера | начальная дистанция 12 при поясе на 17 единицах | 30 |
| Наведение на объект не работало | радиус объекта появляется в реестре только после первого кадра сцены, а эффект читал его сразу | наезд запускается в `useFrame`, когда радиус становится известен |
| Планеты при наезде оказывались ночной стороной | камера отводилась по радиусу наружу, а освещённая сторона обращена к Солнцу | камера ставится между Солнцем и планетой |
| Пояс астероидов выглядел непрозрачным диском | 5 200 точек с плоской альфой 0,85 и размером до 5 px | 3 000 точек, мягкий край, альфа 0,55, размер до 2,6 px |
| Спутники были в 11 раз крупнее правды и стояли не на своих расстояниях | размер и орбита считались от а.е., а не от радиуса планеты | орбита в радиусах планеты со сжатием `r^0.42`, размер уменьшен |
| Подписи далёких тел ложились на диск планеты | `drei/Html` рисуется поверх канваса и не перекрывается геометрией | при наведении подписываются только выбранный объект и его спутники |
| Панель писала расстояние от Солнца, а подписывала «от Земли» | в `distanceM` передавалось не то расстояние | считается настоящее расстояние Земля — объект на выбранную дату |
| Сценарий «три тела» сливался в одно тело за полгода | начальные условия давали немедленное столкновение | равносторонняя конфигурация с околоравновесными скоростями и малой асимметрией |
| Дрейф энергии показывал 1000 % после слияния | слияние неупруго, сравнение с исходной энергией теряет смысл | после слияния берётся новая точка отсчёта, число слияний показано отдельно |
| Символ Юпитера ♃ рисовался «крокозяброй» | его нет в части системных шрифтов | массы подписаны словами |
| Уровень ближайших звёзд был залит белым | радиус звезды считался как `0,3 + L^(1/6)·0,75` — для Сириуса это 1,6 св. года, плюс bloom с порогом 0,12 подхватывал всё | размеры уменьшены примерно в пять раз, порог bloom поднят до 0,45, каркасная сфера-ориентир убрана в пользу колец расстояний |
| Подписи компонентов двойных звёзд накладывались | Сириус A и B разделены 8 угловыми секундами — в кадре это одна точка | подписывается только главный компонент системы, с пометкой кратности |
| Подписи 14 карликовых спутников Млечного Пути сливались в кучу | все лежат в пределах 1 млн св. лет от нас | карлики подписываются только при подлёте |

| Полоса Млечного Пути читалась как серая клякса | контраст клочковатости 0,8 и вычитание пыли 0,6 при амплитуде 0,30 | амплитуда 0,13, контраст снижен вдвое |

## Принятые решения

| Решение | Почему |
| --- | --- |
| Vite + R3F + Capacitor, а не Godot | как предписано ТЗ: веб-стек проверяется headless на каждом шаге, APK собирается из CLI. Непреодолимых стен не встретилось, переключаться не понадобилось. |
| Приложение в подкаталоге `universe/`, корень репозитория не тронут | в корне уже лежит несвязанный Android/Gradle-проект «Stick»; Capacitor в том же корне — конфликт настроек Gradle. |
| Каждый уровень — отдельная сцена со своей единицей длины | от метров до гигапарсеков 27 порядков. У 32-битного float, которым оперирует GPU, около 7 значащих цифр: единая система координат рассыпалась бы на дрожащие полигоны. |
| Уровни не смешиваются кросс-фейдом; стык прикрыт вспышкой и наездом камеры | держать в памяти две сцены с десятками тысяч точек ради полусекунды перехода — плохая сделка на телефоне. Наезд с логарифмической интерполяцией расстояния даёт то же ощущение непрерывности. |
| Переход на следующий уровень по «давлению» на предел зума (0,28 с) | случайный перескок за границу не должен менять масштаб; нужно осознанное продолжение жеста. |
| Свои контролы камеры вместо `drei/OrbitControls` | нужно было ловить упор зума для смены уровня и не конфликтовать с наездами. |
| Размеры тел логарифмически сжаты в обоих режимах масштаба | в масштабе а.е. радиус Земли — 4·10⁻⁵ единицы, то есть заметно меньше пикселя. Сжатие расстояний переключается и подписано, сжатие размеров — нет, потому что альтернатива это пустой экран. |
| Облако Оорта скрыто в сжатом масштабе | сжатие `r^0.42` превратило бы оболочку в 100 000 а.е. в тонкую скорлупу вокруг планет — это дезинформация. |
| `decay=0` у точечного света Солнца | физически верное затухание 1/r² сделало бы Нептун полностью чёрным при видимом Меркурии. Динамического диапазона экрана на 900-кратную разницу освещённости не хватает. |
| Ориентации дисков галактик рандомизированы детерминированным ГПСЧ | настоящие углы наклона известны не для всех галактик Местной группы; подставлять их выборочно хуже, чем честно рандомизировать от сида. |
| Земля стоит «вертикально», а Солнце ходит по эклиптике | работаем в экваториальной системе, где наклон оси 23,44° уже заложен в движение Солнца. Сезоны получаются автоматически и правильно. |
| В песочнице leapfrog, а не Эйлер | Эйлер за сотню витков раскручивает круговую орбиту в спираль: «симуляция гравитации» превратилась бы в демонстрацию ошибки метода. Дрейф энергии показан в интерфейсе — на устойчивых сценариях он не превышает 0,02 %. |
| Шаг симуляции ограничен сверху (1/30 с) | при просадке кадров один большой шаг разрушил бы устойчивость. Побочный эффект: на медленном рендере симуляционное время идёт медленнее реального. |
| APK закоммичен в репозиторий несмотря на `*.apk` в `.gitignore` | по чек-листу собранный APK — это результат работы, он должен быть доступен утром без пересборки. |
| StrictMode отключён | он монтирует компоненты дважды, а сцены R3F при этом дважды строят геометрию на десятки тысяч точек и дважды грузят текстуры. |

## Как проверить

```bash
cd universe
npm install
npm run tex          # текстуры (уже в репозитории, скрипт идемпотентен)
npm run typecheck    # tsc -b
npm run build
npm run shots        # скриншоты всех уровней; падает при любой ошибке консоли

# APK
export ANDROID_HOME=/opt/android-sdk
npx cap sync android && cd android && ./gradlew assembleDebug
```

Источники данных и лицензии ассетов — `ASSETS.md`.
