## Принятые решения

| Решение | Почему |
| --- | --- |
| Стек: Vite + React 19 + React Three Fiber + Capacitor | Как и предписано ТЗ. Веб-стек проверяется headless на каждом шаге, APK собирается из CLI без Android Studio. |
| Новое приложение живёт в подкаталоге `universe/`, корень репозитория не тронут | В корне уже лежит несвязанный Android/Gradle-проект «Stick». Ставить туда Capacitor-проект — конфликт настроек Gradle. Изоляция дешевле. |
| Android SDK доустановлен в `/opt/android-sdk` (cmdline-tools + platform 35 + build-tools 35.0.0) | В образе SDK не было, `ANDROID_HOME` пустой. `dl.google.com` доступен, поставил из CLI. |
| Текстуры планет — solarsystemscope.com, 2K | CC BY 4.0, полный набор для всех планет и Луны. 8K раздули бы APK и не влезли бы в память GPU телефона. |
| У solarsystemscope включена анти-бот защита | Первый заход отдал HTML-капчу вместо картинок. Написал `universe/scripts/fetch-textures.sh`: браузерный User-Agent, Referer, пауза, ретраи и проверка MIME-типа. 19/19 файлов получено. |
| Уровни 7–8 (сверхскопления, наблюдаемая Вселенная) — процедурная генерация по сидированному ГПСЧ | Готовых 3D-моделей сверхскоплений не существует, как и сказано в ТЗ. Генерирую детерминированно (mulberry32), опорные точки — реальные каталожные координаты и красные смещения. В UI помечаю как реконструкцию. |

## Сделано

- [x] Каркас Vite + React 19 + TS, зависимости R3F/drei/postprocessing/zustand.
- [x] Android SDK поставлен и проверен, сборка APK технически возможна.
- [x] Текстуры: 19 файлов, 12 МБ (все планеты, Луна, Солнце, кольцо Сатурна, фон Млечного Пути).
- [x] `src/lib/astro.ts` — юлианские даты, решение уравнения Кеплера методом Ньютона,
      элементы орбит JPL с вековыми скоростями, наклон эклиптики (IAU 2006), звёздное время GMST,
      RA/Dec → декартовы, экваториальные → галактические, сопутствующее расстояние по ΛCDM (Planck 2018),
      цвет по спектральному классу через аппроксимацию излучения чёрного тела.
- [x] `src/lib/rng.ts` — детерминированный ГПСЧ для воспроизводимой процедурной генерации.
- [x] `src/data/planets.ts` — Солнце, 8 планет, 5 карликовых планет: реальные кеплеровы элементы
      JPL (эпоха J2000 + вековые скорости), физические параметры из NASA Fact Sheets, факты, источники.
