# Звук — куда кладутся файлы

Так же, как с графикой: файлов в репозитории нет, пути прописываются в секции
`audio` файла `data/art_manifest.json`. Игра работает без звука — отсутствующий
файл просто не воспроизводится, а не роняет сцену.

## Роли

| Ключ | Когда играет |
|---|---|
| `ui_click`         | нажатие в HUD |
| `event_normal`     | обычная запись в хронике |
| `event_critical`   | сюжетный чекпоинт, раскол, объявление войны |
| `war_declared`     | переход в Акт 3 по войне |
| `ambient_island`   | фон карты |

## Источник

[Freesound.org](https://freesound.org) с фильтром **CC0**. Там, как и на
OpenGameArt, лицензии смешаны: часть файлов под CC-BY и требует атрибуции.
Проверять на странице каждого файла, а не по названию коллекции.

Формат: `.ogg` для длинных фонов (лучше сжимается), `.wav` для коротких
щелчков (нет задержки на декодирование). На Android длинные `.wav` лучше не
держать — это заметный размер APK и лишняя память.
