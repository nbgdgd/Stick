# Подпись приложения — ключи, сертификаты, публикация в RuStore

Эта папка — **самое ценное в проекте после кода**. Здесь лежит ключ, которым
подписываются все релизные сборки. Потеряешь ключ — не сможешь выпустить ни
одного обновления: сторы принимают новую версию только с той же подписью.

> ⚠️ **ВАЖНО**
> 1. **Репозиторий должен оставаться приватным.** Здесь лежат приватный ключ
>    и пароль открытым текстом. Если репозиторий когда-нибудь станет
>    публичным — ключ скомпрометирован, придётся выпускать приложение заново
>    под новым package name.
> 2. Сделай **резервную копию** `release.keystore` + `keystore_password.txt`
>    вне GitHub (флешка, облако). GitHub — не бэкап.
> 3. Ключ действует до **2056 года**. Менять его нельзя.

## Что лежит в папке

| Файл | Что это | Для чего |
|---|---|---|
| `release.keystore` | Хранилище с приватным ключом подписи (RSA-2048) | Им подписываются все релизные APK/AAB. Один навсегда |
| `keystore_password.txt` | Пароль от хранилища и от ключа (они одинаковые) | Нужен при любой сборке и при работе с ключом |
| `upload_certificate.pem` | Публичный сертификат ключа | Загружается в RuStore, шаг 4 «Upload the boot certificate» |
| `make_key.bat` | Готовый скрипт для Windows | Делает `pepk_out.zip` для RuStore, шаг 3 (см. ниже) |
| `artifacts/vpet-waifu-1.0.0.aab` | Подписанная сборка 1.0.0 в формате AAB | Это загружается в RuStore как версия приложения |
| `artifacts/vpet-waifu-1.0.0-release.apk` | Подписанный релизный APK 1.0.0 | Для установки напрямую на телефон |

Параметры ключа:

- **Alias (имя ключа):** `vpetwaifu`
- **Пароль:** в `keystore_password.txt` (один и тот же на оба запроса)
- **SHA-256 отпечаток:** `2C:F7:3D:93:BF:FE:D9:73:E2:77:8C:87:DE:5A:8A:33:B3:BC:08:98:EF:1C:CA:90:12:FB:ED:DB:37:B1:CF:CD`
- **SHA-1 отпечаток:** `08:13:7B:0A:40:78:38:13:61:52:03:E6:E3:8E:0A:CC:8D:5C:FA:AE`
- Действителен до: июль 2056

## Как это работает (в двух словах)

Android-приложение обязано быть подписано цифровым ключом. Подпись — это
«паспорт» приложения: система и сторы считают обновлением только файл,
подписанный **тем же ключом**, что и предыдущая версия. Поэтому ключ создаётся
один раз и хранится вечно.

RuStore при загрузке AAB сам собирает из него установочные APK — и чтобы
подписать их твоим ключом, просит один раз передать ключ в зашифрованном виде
(окно «Upload Signing Key for AAB»). Шифрование делает утилита **pepk.jar** с
ключом шифрования RuStore — расшифровать результат может только RuStore.

## Публикация в RuStore: пошагово

Окно «Upload Signing Key for AAB» в консоли RuStore:

1. **Шаг 1** — кнопкой Download скачай `pepk.jar` (он у RuStore свой,
   публичной ссылки нет). Положи его в одну папку с файлами отсюда:
   `release.keystore` и `make_key.bat`.
2. **Шаг 2/3** — запусти `make_key.bat` двойным кликом (нужна Java 11+,
   установщик: https://adoptium.net). Скрипт покажет пароль — введи его два
   раза по запросу. Появится **`pepk_out.zip`** → загрузи его в шаг 3.
   - В `make_key.bat` уже вшита полная команда с ключом шифрования RuStore
     для аккаунта, где создавалось это окно. Если RuStore покажет **другой**
     ключ шифрования (другой аккаунт/пересоздание) — открой `make_key.bat`
     блокнотом и замени значение после `--encryptionkey=`.
3. **Шаг 4** — загрузи `upload_certificate.pem`.
4. Нажми **Submit Signing Key**.
5. Загрузи `artifacts/vpet-waifu-1.0.0.aab` как версию приложения, заполни
   карточку (описания, скриншоты, возраст 12+) и отправь на модерацию.

## Как собрать новую подписанную версию

Перед сборкой подними `versionCode` (+1) и `versionName` в
`vpet-waifu/app/build.gradle.kts`.

```bash
./gradlew :vpet-waifu:app:bundleRelease :vpet-waifu:app:assembleRelease \
  -PRELEASE_STORE_FILE=$(pwd)/vpet-waifu/signing/release.keystore \
  -PRELEASE_STORE_PASSWORD="$(cat vpet-waifu/signing/keystore_password.txt)" \
  -PRELEASE_KEY_ALIAS=vpetwaifu \
  -PRELEASE_KEY_PASSWORD="$(cat vpet-waifu/signing/keystore_password.txt)"
```

Результат:
- AAB: `vpet-waifu/app/build/outputs/bundle/release/app-release.aab` → в RuStore
- APK: `vpet-waifu/app/build/outputs/apk/release/app-release.apk` → на телефон

Без параметров `-PRELEASE_*` сборка соберётся неподписанной — это защита от
случайной утечки: сам ключ в сборку не вшит.

## Примечания

- **Смена подписи = переустановка.** Старые APK из этого чата были подписаны
  временным debug-ключом. Релизная версия поверх них не установится: сначала
  удалить старую (сохранение при этом стирается). Все версии, подписанные
  `release.keystore`, дальше обновляются друг на друга нормально.
- **Верификация Google (к 2027 для РФ).** Google вводит обязательную
  верификацию разработчиков для установки приложений на сертифицированные
  устройства любыми сторами. Понадобится аккаунт в Android Developer Console,
  регистрация package `com.vpet.waifu` и SHA-256 отпечатка (см. выше).
- Лицензии внешних ассетов приложения — в `vpet-waifu/ATTRIBUTIONS.md`,
  спецификация дизайна — в `vpet-waifu/docs/redesign.md`.
